# Browser Extensions Utilities

This is a mono repo for packages used in browser extension development.

## 🎯 Packages

- ✅ [**webext-message**](./packages/webext-message/README.md) - Type-safe, zero-config messaging library for browser extensions.
- ✅ [**webext-store (planned)**](./packages/webext-store/README.md) - Type-safe, zero-config storage library for browser extensions.
- ✅ [**webext-content-ui**](./packages/webext-content-ui/README.md) - Inject elements into shadow DOM — single or batch anchors.
