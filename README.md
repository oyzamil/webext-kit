# Browser Extensions Utilities

This is a mono repo for packages used in browser extension development.

## 🎯 Packages

- ✅ [**webext-message**](./packages/webext-message/README.md) - Type-safe, zero-config messaging library for browser extensions.
- ✅ [**webext-store**](./packages/webext-store/README.md) - Type-safe, zero-config storage for browser extensions, with an optional React hook. (Used wxt/storage as a base).
- ✅ [**webext-content-ui**](./packages/webext-content-ui/README.md) - Inject elements into DOM — single or batch anchors.
